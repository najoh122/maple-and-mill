# Maple & Mill

## Responsive Changes

The Maple & Mill website was improved using an external CSS stylesheet. Flexbox and CSS Grid were used to create responsive layouts. The navigation, images, text, forms and spacing were adjusted to work well on different screen sizes.

## Testing

The website was tested at:

- 400px wide (mobile)
- 1366px wide (desktop)

The navigation, text, images, forms and page layout were checked at both sizes. No horizontal scrolling or cut-off content was observed.

## Fix Made

The layout was adjusted to use a mobile-first approach. The mobile layout uses a single column, while larger screens use a two-column layout. The navigation was also made flexible for smaller screens.ss
